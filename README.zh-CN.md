# rankai：中英文工作与合作机会搜索引擎（附预先登记的评测）

rankai 从 15 个公开来源（官方 API、RSS、公开的 ATS 职位接口）抓取工作、兼职、悬赏和找合伙人的帖子，去重后用
BM25 + e5 向量召回、交叉编码器重排和学习排序模型排序，并通过 MCP 提供给 AI agent 使用。每一次排序方法的改动，
都在模型新写的留出问题上检验，分析计划在跑结果之前写好。

- 2026-11-17 语料：82,169 条帖子（英文 63,261，中文 18,908），7,298 个重复簇。
- 第四批留出问题（v3，48 个，GPT 出题）：只按重排分排序的 J，nDCG@10 为 0.785，对照组 F（混合检索 + 重排 +
  AI 改写查询 + 手调权重）为 0.654，Holm 校正后 p = 0.0009。默认的学习排序 L 为 0.782，和 J 打平。
- 最大的问题是语料覆盖，而不是排序：48 个问题里只有 15 个能找到好结果，全部是远程岗位。
- 所有标注都来自 AI（两个不同厂商的模型），还没有人工核对。
